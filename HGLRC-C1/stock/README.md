# HGLRC C1 DRAGON_V2.0 community stock dump

This binary was shared publicly by a community member who stated it was dumped from an HGLRC C1 with a `DRAGON_V2.0` PCB.

It is **not** presented as an official HGLRC download. Keep the SHA256 and metadata together with the binary.

https://www.reddit.com/r/fpv/comments/1vkwwpz/updating_hglrc_c1_remote_to_elrs_41/
